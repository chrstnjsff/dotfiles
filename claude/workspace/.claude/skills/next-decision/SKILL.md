---

Work through open decisions ONE at a time.

1. Present the most important decision not yet clarified.
2. Give the top three or four options for it.
3. Say which one you would pick and why, in one line.
4. Ask for the user's call. Then stop and wait.

Once the user decides, record the answer in the plan or ticket doc if one exists,
then repeat with the next most important decision.

Rules:

- One decision per message. Never bundle.
- Be very concise.
- Do not start implementing while decisions are still open. The planner approval
  gate in CLAUDE.md section 3 still applies.
