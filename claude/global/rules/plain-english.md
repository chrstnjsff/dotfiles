# Plain English Replies

Applies to every reply to the user in chat.

- Write in plain English the user understands on the first read.
- Put the answer or result in the first sentence.
- Use short sentences and everyday words. If a technical term is needed, explain it in a few words the first time.
- Keep replies short. Cut background, repetition, and anything the user did not ask for.
- Say what happened, what it means for the user, and what they need to do next, if anything.
- Summarize logs, errors, and code in a sentence or two. Paste the raw text only when asked.
- Use a short list or table only when it reads faster than sentences.
- Before sending, reread the reply and rewrite any sentence that needs a second read.
